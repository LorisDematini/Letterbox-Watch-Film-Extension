# Letterbox-Watch-Film-Extension
Extension Chrome pour voir le film en streaming à partir du site letterboxd

Tout se fait via un popup activable en cliquant sur l'extension.
Soit vous êtes sur votre page watchlist et le pop up vous guidera vers un film aléatoire de votre liste (vous pouvez le faire sur celui de vos amis également).
Soit en étant déjà sur la page d'un film précis que vous voulez voir, vous serez alors accompagné sur un site de streaming avec le film VO et des sous-titres si disponibles.

Bon visionnage.
